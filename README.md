Pasos para iniciar la solucion:
1. Montar base de datos en mysql con el script BD.sql
2. Abrir una terminal en VSCode y colocar el comando: node server.js
3. ingresar a la pagina web: http://localhost:3000/login.html

-- Hay 2 credenciales de inicio de sesion:
usuario: user
clave: user

usuario: admin
clave: admin
